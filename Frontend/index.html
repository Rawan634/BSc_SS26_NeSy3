Quick Guide

How To Use AI Logic Tutor

Everything you need to get clear answers and clean verified proofs.

🧠 AI Tutor Mode

Ask conceptual logic questions and get concise teaching explanations from the tutor model.

  • Type your question in the AI panel.
  • Click Ask Tutor.
  • Use Ctrl+Enter for faster submit.

✅ Verified Proof Mode

Generate a validated Fitch-style proof with rule explanations and correction metadata.

  • Enter one premise per line.
  • Enter one goal formula.
  • Click Solve Verified Proof.

📘 Input Format Tips

Use standard propositional symbols for best parsing and validation.

  • Implication: P → Q
  • Negation: ¬P
  • Disjunction: P ∨ Q
  • Conjunction: P ∧ Q

🔎 Reading Proof Lines

Each line can show short and detailed guidance to explain the logic behind the step.

  • Hover for short explanation.
  • Click to expand full teaching text.
  • Goal line is highlighted in green.
