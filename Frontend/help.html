How to use AI Logic Tutor

A quick walkthrough for AI Tutor Mode and Verified Proof Mode.

Use this mode for general logic questions. Type a question and click Ask Tutor. The app sends your request to POST /ask_ai and displays the explanation in the response panel.

Enter premises one per line and a single goal formula. Click Solve Verified Proof to send the request to POST /solve_verified. The returned proof is rendered as Fitch-style lines.

Premises should be plain logic statements such as P → Q or ¬R. The goal should be the formula you want to prove, such as Q or ¬P.

Hover Explanations

Hover any proof line to see the short explanation for the rule used on that line.

Click Expansion

Click a proof line to expand the full explanation, example usage, and any correction history.

Corrected Lines

When the backend repairs a line, it is visually highlighted and the original error message is shown inside the expanded details.
